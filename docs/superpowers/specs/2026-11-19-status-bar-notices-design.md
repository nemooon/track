# 通知をステータスバーにまとめる（小さな変更）

## 目的
トーストは Web アプリらしく、「保存しました」が操作のたびに出てうるさい。Zed のように、知らせる必要のあるものだけを画面下のステータスバーに静かに出す。

## 決めたこと（利用者が B 案を選択）
- トースト（gpui-component の Notification）を使うのをやめる。
- 成功は何も出さない（画面がすぐ変わり、ヘッダーのドットがきらめくため）。
- 削除は AI の通知と同じ形でステータスバーに出す：「1件削除しました：<題名>　元に戻す　×」。元に戻すと同じ内容で作り直す（今のトーストの「元に戻す」と同じ動き）。
- 失敗（更新・作成・削除）はステータスバーに赤字で出し、× で閉じるまで残る。
- 読み込み失敗の帯（再読み込みボタン付き）は今のまま。

## 私の判断（直してよい）
- 自分の操作の知らせは一つだけ持ち、新しいものが来たら置き換える。AI の通知とは別の枠で、両方あるときは並べる（自分の操作が左）。
- 自分の操作の知らせは自動では消えない（AI の通知と同じ）。
- ⌘Z での取り消しは今回入れない。

## 考えた方法
- A（全部ステータスバー）：「保存しました」も残るのでうるささが変わらず不採用。
- C（通知センター）：自分の操作の結果には向かず不採用。

## 作業
1. `AppState` に自分の操作の知らせ（削除／失敗）を持たせ、ステータスバーに出す。テスト：削除で出て元に戻せる、失敗で赤字が出る、成功では何も出ない。
2. カレンダーのトーストをすべてこの知らせに置き換える。
