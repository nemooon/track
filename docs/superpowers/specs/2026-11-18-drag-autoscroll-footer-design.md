# ドラッグ中の自動スクロールと日ごとの合計フッター（小さな変更）

## 目的
- 記録を長く動かすとき、いちいち離してスクロールし直さずに済むようにする。
- 日ごとの合計を列の下にまとめ、ヘッダーを日付と印だけにする。

## 決めたこと
- 自動スクロールは上下だけ。左右の端で週は切り替えない（落とす先が分かりにくくなるため）。
- 対象は、記録の移動・上下の端の伸縮・空き場所からの新規作成の三つのドラッグ（利用者は移動を挙げた。残り二つは同じ動きにそろえるという提案）。
- 時間の部分の上端・下端から 40px 以内で始まり、端に近いほど速い。端の外に出ても最大の速さで続く。
- スクロール中も、つかんでいる記録はマウスの位置についてくる（マウスを止めていても時刻が進む）。
- 時間の部分のすぐ下に、列にそろえた一行のフッターを足し、各日の合計を出す。合計がない日は空。
- ヘッダーからは合計を外す。画面下の帯の「合計」はそのまま。

## 考えた方法
- 自動スクロール: マウスが動いたときだけスクロールする方法は、端で止めると動かないので不採用。端にいる間はタイマーで少しずつ進め、そのたびに最後のマウス位置でドラッグを計算し直す。
- フッター: スクロールの中（24時の下）に置くと、見るためにスクロールが要るので不採用。スクロールの外に固定する。
