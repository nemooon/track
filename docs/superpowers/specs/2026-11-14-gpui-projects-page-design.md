# GPUI 版 プロジェクト画面の作り直し 設計（短）

日付: 2026-11-14 / ブランチ: `gpui-native`

## 目的
設定の「プロジェクト」を、利用者のいつもの流れ（クライアントを作る → その下にプロジェクトを足す → 色を選ぶ）に合わせて作り直す。利用者:「良くしたい」「ガラッと変えて OK」。タグは使っておらず、終わった案件もアーカイブしていない。

## 検討した案（モックアップで比較）
- **A. クライアントでまとめた一覧＋右に詳細（採用）**
- B. 1 行で追加＋その場で編集: 速いが、色やクライアントを変える場所が行の中で窮屈
- C. クライアント → プロジェクトの 2 列: クライアントをまたいで全体を見渡せない

## 決まったこと（利用者）
- 案 A
- 変更は **すぐ保存**（保存ボタンなし）

## 作り（Claude の案、利用者に提示済み）
- **左の一覧**: クライアントの見出しの下に、そのプロジェクトを並べる（色の点＋名前）。見出しの「＋」でそのクライアントにプロジェクトを追加し、追加した行を選んで右の名前欄にフォーカスする（色は自動で 1 つ選ぶ）。一番下に「＋ クライアント」と、畳んだ「アーカイブ（N）」
- **右の詳細（プロジェクト）**: 名前・クライアント（選択）・色（20 色＋スポイト）・今月の時間と最終記録日・アーカイブ／元に戻す
- **右の詳細（クライアント）**: 名前・プロジェクト数・アーカイブ／元に戻す
- **保存**: 色・クライアント・アーカイブは押した時点で保存。名前は Enter か入力欄から離れたときに保存。空の名前は保存せず元に戻す。保存に失敗したら右の詳細にエラーを出し、表示は保存済みの値に戻す
- **タグ**: 設定の左の項目に「タグ」を新設して移す（中身は今のタグの一覧・追加・名前・色・削除のまま）
- **見た目**: Zed の一覧のように行を詰め、選択中の行だけ面を付ける。意味の色（`Palette`）だけを使う
- 何も選んでいないときは、右に「左からプロジェクトを選ぶか、クライアントの＋で追加」と案内を出す。開いたときは最初のプロジェクトを選んでおく

## やってはいけないこと
- 既存の規則（名前の長さ・色の形式・アーカイブの連鎖・タグ名の重複）を変えること（track-core の関数をそのまま使う）
- 本物の `~/.track` に触れること

## 実装者に任せること
- 一覧と詳細の幅、行の高さ
- 「今月の時間」の取り方（既存のレポート集計を使ってよい）
